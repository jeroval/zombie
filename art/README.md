# Sources et droits des assets

Conserver ici les sources éditables, recettes, références et preuves de licence
par asset. Exporter les fichiers utilisables par Godot dans `game/assets/`.
Garder séparés les composants qui doivent pouvoir être modifiés ou remplacés.

Avant toute génération : rechercher dans le projet puis dans les bibliothèques
compatibles. Garder l'URL, l'auteur, la licence et les obligations d'attribution.
Un export candidat nécessite une inspection Blender puis une validation Godot.

Les fixtures techniques sont dans `.tools/verification` et `game/studio_fixtures`
(ignorés par Git). Elles ne sont pas des assets de production.
