# Dernier Signal — guide joueur

## Lancer le jeu

Sous Windows 64 bits, ouvrir `Dernier-Signal.exe`. Le jeu est autonome : Godot,
Python, Blender, Codex et une connexion Internet ne sont pas nécessaires.

Cette version locale n'est pas signée avec Authenticode. Avant de la distribuer
ou de la lancer depuis une copie, comparer l'empreinte SHA-256 de l'archive avec
le fichier `Dernier-Signal-windows-x86_64.zip.sha256` livré à côté du ZIP.

## Mission

Le refuge ne peut plus appeler les secours. Explorez le quartier et récupérez :

- la batterie dans la clinique ;
- le carburant dans le garage ;
- le module d'antenne dans le relais télécom.

Revenez à la radio, envoyez le signal, tenez pendant 90 secondes puis rejoignez
la balise au nord. Les caisses marquées **RÉSERVES** donnent une fois des
munitions et un soin. La mort ou l'évacuation ouvre un écran de résultat et
permet de recommencer immédiatement.

| Action | Commande |
| --- | --- |
| Marcher | ZQSD, WASD ou flèches |
| Regarder | Souris |
| Tirer | Clic gauche |
| Viser | Clic droit |
| Recharger | R |
| Mêlée | V |
| Courir | Maj |
| Interagir | E |
| Utiliser un soin | F |
| Pause et options | Échap |

## Options et accessibilité

Le menu principal et la pause règlent séparément le volume général, l'ambiance,
les effets et les voix. La sensibilité souris, le champ de vision, les secousses
de caméra et le plein écran sont configurables et persistants. Les messages
radio sont aussi affichés à l'écran. Les objectifs combinent forme, couleur,
texte et position ; aucune information de progression ne dépend uniquement du
son ou de la couleur.

Les meilleurs temps d'évacuation et records de neutralisations sont conservés
localement. Les paramètres et résultats se trouvent dans le dossier utilisateur
Godot et peuvent être supprimés pour réinitialiser le jeu.
