# zombie

Environnement Godot 4.7, orchestré avec Godot Asset Cloud et le skill
`studio-3d-local`. Le dépôt contient une scène de calibration, sans gameplay.

```powershell
uv sync --locked
uv run --locked python scripts/studio.py doctor
uv run --locked python scripts/studio.py open
```

Commandes, MCP, routes 3D, validations et limites : [guide du studio](docs/STUDIO.md).
