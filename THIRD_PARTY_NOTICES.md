# Dernier Signal — composants tiers

Les modèles, sons et autres contenus originaux de Dernier Signal restent sous le
contrôle de leur auteur. Ce fichier recense les composants tiers distribués avec
le jeu.

## Godot Engine

Le jeu utilise Godot Engine 4.7.2, distribué sous licence MIT. L'archive Windows
contient `GODOT_COPYRIGHT.txt`, généré depuis le moteur, avec les notices de Godot
et de ses bibliothèques tierces.

- Site et licence : https://godotengine.org/license

## Quaternius — Zombie Apocalypse Kit

Le personnage infecté, ses animations, le pistolet, les véhicules et plusieurs
accessoires sont adaptés du **Zombie Apocalypse Kit** de Quaternius, publié sous
licence CC0 1.0.

- Source : https://quaternius.com/packs/zombieapocalypsekit.html
- Licence CC0 1.0 : https://creativecommons.org/publicdomain/zero/1.0/

## Piper — voix française SIWIS

Les quatre messages radio ont été synthétisés avec le modèle Piper
`fr_FR-siwis-medium`. Son model card indique que le jeu de données SIWIS est sous
licence CC BY 4.0.

Attribution : Junichi Yamagishi, Pierre-Edouard Honnet, Philip Garner et
Alexandros Lazaridis (2017), *The SIWIS French Speech Synthesis Database, 2016*,
University of Edinburgh, Centre for Speech Technology Research,
https://doi.org/10.7488/ds/1705.

- Model card : https://huggingface.co/rhasspy/piper-voices/blob/main/fr/fr_FR/siwis/medium/MODEL_CARD
- Licence CC BY 4.0 : https://creativecommons.org/licenses/by/4.0/
- Modèle : SHA-256 `641d1ab097da2b81128c076810edb052b385decc8be3381814802a64a73baf99`

Les voix sont intégrées sous forme de fichiers audio générés. Les poids du modèle
Piper ne sont pas distribués avec le jeu.
